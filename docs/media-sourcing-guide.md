# AiPhonix 素材来源指南（图片 / 声音 / 视频）

> 建立日期: 2026-08 | 维护人: （待填）
> 适用范围: 所有进入 AiPhonix 产品（Android App / Web 端 / 服务端素材）的图片、声音、视频、字体、动画素材。
> 关联文档: 资产台账 [`docs/video-assets-audit.md`](video-assets-audit.md)（视频逐条审计）；本指南的"入库四步"是素材准入的强制流程。

---

## 1. 总原则

**只从三条合法路径进素材，一条红线绝不碰。**

| 路径 | 说明 | 成本 | 风险 |
|---|---|---|---|
| **原创自制** | 自绘/自拍/自录、TTS 合成、用工具自行生成，版权完全归我方 | 中 | 低 |
| **正版商用授权** | 素材库订阅/单买，条款明确允许商业用途并作为产品一部分分发 | 低~中 | 低 |
| **开放许可** | CC0 公有领域、CC-BY（须署名）、开源协议素材（Apache/MIT 等） | 零 | 低（须留档署名） |

🔴 **红线（一律禁用）**：
- 任何"网上下载""免费下载站"来源（含百度网盘资料包、各种"素材合集"）
- 从其他 App / 网站 / 视频平台**提取、翻录、截图**的内容（YouTube、B 站、抖音、其他 App 拆包等）
- 标注 "no copyright" / "non-copyright" / "个人学习用" 等非正式授权的资源
- 未经许可的**知名角色、形象、绘本、动画截图**（形象/角色使用需单独授权，与音乐、视频版权分开）

## 2. 视频素材

### 2.1 教学演示类（字母 / 拼音 / 朗读示范）→ 首选自制

| 方案 | 工具 | 说明 |
|---|---|---|
| 演示动画 | Canva 视频 / Keynote / PPT 模板导出 MP4 | 用模板 + 我方 TTS 朗读即成片，版权归我方 |
| 轻量动画 | Lottie（开源）/ Flourish | 矢量动画可随代码分发，无需存 MP4 |
| AI 生成视频 | 即梦 / 可灵 / Runway 等 | 留生成记录；不模仿现成作品风格；注意内容标识要求 |

### 2.2 故事 / 动画类 → 只能授权或自制

| 来源 | 说明 | 注意 |
|---|---|---|
| 原创自制动画 | 简化场景 + 矢量形象 | 最干净，但成本高 |
| CC0 实拍素材 | Pexels Videos / Pixabay Videos / Coverr | 适合背景/示范镜头，不适合字幕教学 |
| 商用动画/模板 | Envato Elements / Storyblocks / Canva（订阅） | 注意"不得单独再分发原始素材文件"条款 |
| 正版儿童内容合作 | 版权方授权（引进方/出版社） | 周期长、成本高，但唯一可大规模使用的动画片路径 |

> ⚠️ 所有素材库通用条款陷阱：允许"作为你产品的一部分"使用，**禁止把原始素材单独再分发/转卖**；"个人版"套餐不能商用；授权截图必须存档。
>
> 🔴 现状警示：`Big_Muzzy`（BBC 动画，yt-dlp 从 YouTube 下载）属于红线资源，处置见台账第 2 节——**从正式构建排除或替换**。

### 2.3 字幕

- 我方 TTS 生成的字幕脚本版权归我方；对受版权保护作品**转录/翻译的字幕属于演绎作品**，同样需要授权（当前 Whisper 生成的 Big Muzzy 字幕即属此类）。

## 3. 图片素材

| 用途 | 推荐来源 | 协议/说明 |
|---|---|---|
| 图标 | Material Symbols / Ionicons / Iconify | Apache / MIT，✅ 直接商用 |
| 插画/配图 | Canva 商业版（订阅含商用插画）、Figma 自绘、AI 生成（即梦等） | AI 生成国内版权认定有不确定性，用主流工具 + 留生成记录；不模仿现成绘本/动画风格 |
| 免费照片 | Unsplash / Pexels / Pixabay | CC0；儿童 App 慎用真人照片（肖像权），优先插画 |
| 付费图库 | 摄图网 / 千图网 / Adobe Stock / Shutterstock | 购买"企业商用"档位，不要"个人版" |
| 学习用 OCR/词卡素材 | 自建词库配图（自绘） | 遵循 AI/LLM 规范，词库数据走生成台账 |

### 字体（算图片类素材）

| 类型 | 推荐 | 说明 |
|---|---|---|
| 免费商用字体 | 思源黑体 / 思源宋体（SIL OFL）、阿里巴巴普惠体、站酷小薇LOGO体等 | OFL/免费商用授权，可内置 APK 分发 |
| 🔴 禁止 | "某某字体下载站"免费字体、未注明授权字体 | 字体侵权是儿童 App 高发投诉点 |

## 4. 声音素材

| 用途 | 推荐来源 | 说明 |
|---|---|---|
| 朗读/配音 | 百度 TTS（现有）、edge-tts（备用） | 合成音频版权归我方；**确认引擎商用条款**（商用可能需购买授权/签署协议），百度 TTS 商用请查官方授权政策 |
| 音效（按钮/对错/打卡） | Mixkit（免费商用）、Pixabay Sound Effects（CC0）、ZapSplat（免费版须署名） | 建议优先 Mixkit / Pixabay，省去署名义务 |
| 背景音乐 | Pixabay Music / Chosic / Incompetech（CC-BY 须署名） | 署名信息存 `docs/media-licenses/` |
| 儿歌/童谣 | 公有领域（民间童谣、作者逝世超 50 年的作品）或签约作曲家原创 | 🔴 当代儿歌（早教公司作品等）必须授权，歌词+曲分别有版权 |
| 🔴 禁止 | YouTube 提取、其他 App 拆包提取、B 站音频提取 | — |

## 5. TTS / AI 生成素材的附加要求

- TTS 合成音频：版权归我方，但**引擎服务条款需允许商用**（逐项确认并留档）
- AI 生成图片/视频/文案：符合《生成式人工智能服务管理暂行办法》（侵权禁止 + 内容标识），保留 `工具名 + 提示词 + 生成时间` 记录（项目已有 `llm_call_logs.json` 机制，可扩展此模式）
- AI 生成的图片/视频若进入商业化分发，建议优先用大厂商用工具并查阅其内容授权条款

## 6. 入库四步（强制准入流程）

> 任何新素材（图片/声音/视频/字体）合入代码库前，必须完成以下四步，缺一不可。

1. **来源登记**：记录 `文件名 / 来源渠道 / 授权类型 / 凭证（链接或订单号）`
2. **授权留档**：许可证截图、订单号、下载页 URL 存入 `docs/media-licenses/`
3. **台账登记**：
   - 视频 → `docs/video-assets-audit.md`
   - 图片 / 声音 / 字体 → 本指南附录表（或另建 `docs/media-assets-audit.md`，见第 7 节）
4. **复查确认**：发版前抽查——CC-BY 署名是否还原、授权是否过期、凭证是否齐全

> 未完成四步的素材，视为未授权，禁止合入。
