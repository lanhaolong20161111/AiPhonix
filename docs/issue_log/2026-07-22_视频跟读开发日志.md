## 1. 字幕不加载问题排查与修复

### 问题现象
- 视频正常播放（ExoPlayer 状态 2/3）
- 字幕卡片始终显示"解析: 0条" 或 "（等待字幕...）"
- 字幕文件 `Big_Muzzy_Ep01.en.srt` 已正确推送到 `/sdcard/Android/data/com.example.ai/files/videos/`

### 排查过程

| 步骤 | 检查项 | 结果 |
|------|--------|------|
| 1 | 文件是否存在 | `adb shell ls` 确认文件在正确位置 |
| 2 | SRT 内容是否正常 | `adb shell head -20` 内容正常，格式正确 |
| 3 | SRT 编码 | 无 BOM，标准 UTF-8 |
| 4 | 扫描是否找到文件 | 添加诊断标签，显示文件路径正确 |
| 5 | 解析是否成功 | **解析: 0条**，SrtParser.parse() 返回空 |

### 最终根因

**Whisper 生成的 SRT 时间戳小时位只有 1 位数字**（`0:00:04,934`），而 `SrtParser.kt` 的正则写死了 `\d{2}`（必须2位小时）：

```kotlin
// 修复前（Bug）
private val TIMESTAMP_REGEX = Regex("""(\d{2}):(\d{2}):(\d{2})[,.](\d{3})""")
//                                     ^^^^  小时必须2位 → "0" 不匹配！

// 修复后
private val TIMESTAMP_REGEX = Regex("""(\d{1,2}):(\d{2}):(\d{2})[,.](\d{3})""")
//                                     ^^^^^^  1-2位，兼容 "0" 和 "00"
```

### 影响范围
- **yt-dlp 自动字幕**: 通常小时位为 `00`（2位） → 不受影响
- **Whisper/sherpa-onnx 生成的字幕**: 小时位为 `0`（1位） → 全部被跳过

### 附带修复
1. **字幕同步空覆盖**: `findCurrentSubtitle` 在位置=0 时返回 null，把初始首条字幕清空 → 改为 `if (sub != null && sub != currentSubtitle)`：null 跳过不覆盖
2. **自动播放**: `playWhenReady = true`（加载视频后自动播放）
3. **首条字幕预加载**: `currentSubtitle = subtitles[0]`（不等视频位置）
