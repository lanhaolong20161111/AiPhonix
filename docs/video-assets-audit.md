## 2. 🔴 重大风险项：Big Muzzy（BBC 动画）

**事实（来自 `docs/issue_log/2026-07-22_视频跟读开发日志.md`）**：

- 来源：`C:\Users\lhl20\Desktop\youtube_playlist\`，通过 **yt-dlp 从 YouTube 下载**，共 12 集
- 字幕：`sherpa-onnx Whisper` 本地生成的 `.en.srt`（属对该片字幕的演绎，同样受版权约束）
- 分发方式：`adb push` 到设备 `/sdcard/Android/data/com.example.ai/files/videos/`

**定性**：Big Muzzy 是 BBC Studios 的知名儿童教育动画，受《著作权法》保护。下载 + 向学生（不特定公众）提供点播，构成未经许可的**信息网络传播**，且属于**故意规避版权保护**（yt-dlp 用于下载 YouTube 受保护内容），即便当前仅限自有设备测试，一旦形成学生可见的正式功能即构成侵权风险。字幕由 AI 转录也属于对创作作品的复制/演绎。

**处置选项（三选一）**：

| 选项 | 说明 | 成本 |
|---|---|---|
| A. 取得授权 | 与 BBC Studios / 版权方（或国内引进方）签署授权协议，明确"面向未成年学习用户的信息网络传播权 + 期限 + 地域" | 高，周期长 |
| B. 替换为有授权内容 | 改用：自研动画（原创 or 购买商用动画模板）、正版授权的儿童内容平台分发、CC 协议素材 | 中 |
| C. 仅保留本地自测 | 明确该功能**不进正式发布版**，仅开发者本机 adb 测试用；正式包移除相关入口与资源 | 零（合规角度） |

**📌 我建议：短期立刻执行 C（从正式构建中排除），中期执行 B。** 在未授权前，任何"学生能用它"的分发路径都不应保留。

## 5. 内容合规检查（面向未成年学生，逐项确认）

- [ ] 无《未成年人网络保护条例》负面清单内容：色情 / 暴力 / 血腥 / 恐怖 / 赌博 / 诱导自伤自杀 / 教唆犯罪 / 歪曲历史 / 邪教迷信
- [ ] 页面有**适龄提示**（如"适合 6–12 岁"）
- [ ] 无诱导充值 / 诱导分享 / 不利于未成年人身心健康的广告
- [ ] 隐私政策 + 用户协议中已声明：视频内容版权归属、仅限个人学习使用、禁止下载再传播
- [ ] 面向学校/机构场景时已完成**教育部教育移动互联网应用程序备案**
- [ ] 服务器/下载源在**境内**（ICP 备案 + 等保 2.0 定级）

## 6. 技术防扩散检查

- [ ] 视频只存放于**应用私有目录**（`getExternalFilesDir()` 或 assets），不做“保存到相册”入口 ✅（现状符合）
- [ ] `AndroidManifest` 云备份策略不带走视频（`dataExtractionRules` 排除视频目录）— ⚠️ 当前 `allowBackup="true"` 且无排除规则，**待修复**
- [ ] 用户协议禁止下载后再传播；如未来做在线播放，URL 不暴露可直链下载的静态文件
