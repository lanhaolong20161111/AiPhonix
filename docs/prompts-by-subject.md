## 1. 总表：三学科各环节用哪个提示词

| 环节 | 语文 | 英语 | 数学 |
|---|---|---|---|
| **结构化 OCR（主路）** | `DOUBAO_OCR_JSON_PROMPT` | `DOUBAO_OCR_JSON_PROMPT_EN` | `MATH_OCR_JSON_PROMPT` |
| 结构化·省略注音版 | `DOUBAO_OCR_JSON_PROMPT_NO_POLY` | — | — |
| **纯文本 OCR（回退）** | `DOUBAO_OCR_PROMPT` | `DOUBAO_OCR_PROMPT_EN` | `MATH_OCR_PROMPT` |
| **排版整理（兜底）** | `DEEPSEEK_RELAYOUT_PROMPT` | `DEEPSEEK_RELAYOUT_PROMPT_EN` | — （数学无 relayout） |
| **表格页（覆盖式）** | `DOUBAO_TABLE_OCR_PROMPT`（三学科共用） | 同左 | 同左 |
| OCR 后清洗（LLM） | `llmFilterOcrText` 内联提示词 | — | — |

**关键事实**：三学科的提示词**不是同一份加变量**，而是三份独立写的文本。语文/英语是「结构分类 + 逐行保真」两段式，数学是「禁格式标记 + 竖式对齐」另一套。

## 2. 语文（Chinese）

### 2.1 主路：`DOUBAO_OCR_JSON_PROMPT`（结构化一次成型）

```
任务：识别小学语文课本/作业照片，逐行保真转录并按课文结构直接输出 JSON（一步完成，不需两步）。
【第一步·先看整体】先判断图片方向：横放/倒置/倾斜先在脑中纠正到正向，再按正向读。
【核心硬性规则——逐行保真】
1. 图片上有几行文字，你就输出几条 line；每条 line 单独占一行，禁止合并/拆分行。
2. 每行列数必须与图片严格一致：汉字、拼音字母、声调、标点、括号、数字、下划线、√、①等一个不漏，不得多字。
3. 汉字上方的注音拼音，拼音行与汉字行各自独立成一条 line。
4. 空白填空横线按原样输出下划线，保留该行空格位置。
5. 缩进/居中对齐尽量保留。
【结构分类】按阅读顺序把整页整理成 blocks 数组：
- 大标题→type=title（align=center）
- 小标题/单元名/页眉/页码→heading（页码 align=right）
- 题目→question；选项→option
- 正文→body（首行 indent=1，续行 indent=0；其余 indent=0）
- 旁批/注脚/提示→note
- 表格→type=table，text 用 HTML <table> 还原跨行 rowspan / 跨列 colspan 合并
【多音字】polyphones：读错明显的多音字给出正确带声调拼音（如 还:hái），只标确定的。
【版面结构（重要）】
- 每个自然段单独一个 body 块：原图换一段，blocks 里就新起一个 body 块，禁止把多个自然段并进同一个块。
- 标题/小标题各自单独成块；题目与它的选项各自单独成块。
- 禁止改写、润色、总结、简化、翻译任何文字；禁止调整语序；禁止增删内容。
【输出】只输出一个 JSON，不要任何解释、不要 markdown 包裹：
{"blocks":[{"type":"title|heading|body|question|option|note|table","align":"left|center|right","lines":[{"text":"行","indent":0}],"polyphones":{"字":"带声调拼音"}}]}
【不要重复输出】不要写 text 字段——块的全文就是 lines 逐行拼接的结果，
再写一遍是重复劳动，会让输出翻倍、拖慢速度。表格 table 是唯一例外：
text 填完整的 HTML <table>，lines 只放一条（内容与 text 相同）。
【最后自检】输出前数一遍：lines 总行数是否与图片一致。
```

### 2.2 `DOUBAO_OCR_JSON_PROMPT_NO_POLY`

与 2.1 **逐字相同，只删掉 `【多音字】polyphones` 整段**，输出 schema 里也去掉 `polyphones` 字段。
用于 `poly_async=1`（注音由后台 `runPolyphonesAsync` 补），避免重复输出拉长生成、触发 max_tokens 截断。

```

```


### 2.5 OCR 后清洗（`llmFilterOcrText` 内联提示词，非 prompts.ts）

system_prompt：`你是一个只做文本清洗的 OCR 后处理助手，输出纯文本。`

```
下面是一张小学语文试卷/课本页面经 OCR 识别出的文本，可能混有噪声。请做如下清洗：
1) 只保留题目/正文（课文、题目、选项、答案、标题等），删除所有非题目信息（页眉页脚、页码、水印、广告、图标文字、纯分隔线、装饰性乱码）；
2) 删除所有括号（）/( )，包括空括号（ ）（答案、注释、小提示、填空横线均按需求全部过滤）；
3) 删除下划线符号 _（老师标注线/填空横线在 OCR 里常被识别成连续下划线）；
4) 把相邻的正文行合并为通顺段落，不同段落之间用「一个空行」分隔。
严格要求：①不要改写、纠错或补充正文内容；②不要输出任何解释或标记，只输出清洗并排版后的纯文本；
③如果整段都是噪声，输出空内容。

原文：
{text}
```

## 4. 数学（Math）

> 数学与语英最大的差别：**明令禁止一切 LaTeX/HTML/markdown 标记**，并要求**保留行首空格做竖式对齐**（解析端须 `keepLineSpaces: true`）。

### 4.1 主路：`MATH_OCR_JSON_PROMPT`

```
任务：精确识别小学数学课本/作业照片，原样还原全部文字、数字、算式、填空横线，按结构直接输出 JSON（一步完成，不需两步）。
【第一步·先看整体】先判断图片方向：横放/倒置/倾斜先在脑中纠正到正向，再按正向读。
【核心硬性规则——逐行保真】
1. 图片上有几行文字，lines 里就输出几条；每行单独一条，禁止合并/拆分/删行。
2. 每行的字符必须与图片严格一致：数字、运算符、字母、单位、标点、括号、下划线、□、√、①②等一个不漏，也不得多字。
3. 竖式计算的每一行（含进位/借位小字、横线、结果）都单独输出一条 line，并**保留每行前面的空格**（竖式靠空格对齐，禁止压缩空格）。
4. 图片里空着的方框/横线按原样保留（方框写 □，填空横线写 ____），不要脑补答案、不要做题。
5. 算式**独占一条 line**，不要跟在题干文字后面。
【禁止格式标记】禁止输出任何 LaTeX/HTML/markdown 标记（如 \frac、\boldsymbol、\underline、\boxed、\quad、\square、\times 等一律不许出现）。分数写成 a/b，方框写 □，填空横线写 ____。
【结构分类】按阅读顺序整理成 blocks：
- 大标题（如「第一单元 练习一」）→ type=title（align=center）
- 小标题（如「一、计算下面各题」「二、填空」）→ heading
- 题目题干→question；可选项（A./B./C. 或 ①/②/③）→option 单独成块
- 算式、竖式、计算过程→body（一个 body 块放同一道题的算式/竖式，块内逐行保真）
- 旁批/注脚/提示→note
【indent】数学一律 indent=0（不缩进）；竖式各行也不要加缩进，靠行内空格对齐。
【不要重复输出】不要写 text 字段——块的全文就是 lines 逐行拼接的结果。
【输出】只输出一个 JSON，不要任何解释、不要 markdown 包裹：
{"blocks":[{"type":"title|heading|body|question|option|note","align":"left|center|right","lines":[{"text":"行","indent":0}]}]}
【最后自检】输出前数一遍：lines 总行数是否与图片一致，每个算式是否独占一行。
```

### 4.2 纯文本回退：`MATH_OCR_PROMPT`

```
任务：精确识别小学数学课本照片，原样还原课本全部文字、数字、算式、填空横线，区分标题、例题、对话框、竖式计算，不要脑补答案，图片里面空着的方框、横线就原样保留为空。
【逐行保真】图片上有几行文字就输出几行，禁止合并/拆分/删行；每行字符数与图片一致。
【禁止格式标记】禁止输出任何 LaTeX/HTML/markdown 标记（如 \frac、\boldsymbol、\underline、\boxed、\quad、\square、\times 等一律不许出现）。算式全部用普通文本：分数写成 a/b，方框写成 □，填空横线写成 ____，空格用普通空格。
【版面结构】保留原图的段落划分与空行；题目和它的算式**分行输出**——算式另起一行，不要跟在题目文字后面。
只输出识别文本本身，不要解释、不要做题。
```

## 5. 三学科共用：`DOUBAO_TABLE_OCR_PROMPT`

触发条件：`isTable`（整页判定为表格页）。**三学科共用同一份**，覆盖各自的默认提示词。

```
任务：识别图片内容，文字与表格混排时分别还原。文字照常按阅读顺序输出；**表格部分单独用 HTML <table> 输出**，且要还原跨行/跨列合并。
0、先判断图片方向：横放/倒置请先在脑中纠正到正向再读。
输出规则：
1. 图片里的普通文字（标题、段落、题目、说明）按原顺序正常输出，换行分段尽量还原，不额外解释、不做题。
2. 图片里遇到的**表格**：单独输出一段 HTML <table>，放在该表格对应文字位置，且：
   - 用 <table> <tr> <td>/<th> 组织，每行的列数要一致（列数=图片最细列数）
   - **跨行合并**用 rowspan，**跨列合并**用 colspan（如 表头"音序查字法"跨2列 → <th colspan="2">）
   - 两行表头也两行输出（大表头 + 子表头子列），子表头挂在对应大表头列下
   - 文字100%原样，不删减选项/括号/√/①②③
3. 一张图里可能没有表格（纯文字），或既有文字又有表格——按图片实际来，没表格就不要输出 <table>。
4. 除表格用 HTML 外，其余文字直接用文本输出，不要把所有内容包在 HTML 里。
不要额外解释，只输出识别内容。
```

## 6. 三学科关键规则差异对照

## 7. ⚠️ 提示词 vs 后处理：正面冲突（§0.5 提案依据）

三份提示词**都要求「填空横线按原样输出下划线」**，但下游清洗的行为**三学科不一致**：

| 学科 | 提示词 | 后处理实际行为 | 出处 |
|---|---|---|---|
| 语文 | 要求保留下划线 | **删掉** | `aiTextUtils.ts:607` `s.replace(/_+/g, "")`；另有 `chinese.ts` 内联提示词第 3 条「删除下划线符号 _」 |
| 英语 | 要求保留下划线 | **删掉** | `english.ts:306` `stripQuestionNoise(text)` |
| 数学 | 要求写成 `____` | **保留** | `mathClean` 无下划线删除逻辑 |

补充事实：
- `stripQuestionNoise` 还会**删除所有单层括号（含空括号）**。
- `stripQuestionNoise` 的调用点**只有语文与英语**（`chinese.ts:452`、`english.ts:306`、`routes/ai_chinese.ts:182`），**数学不调** —— 所以「整行下划线」规则不会误伤竖式的计算横线。
- 前端**已有填空位渲染机制**：`web/src/lib/paragraphFlow.ts` 的 `BLANK_RE` / `splitBlanks`，目前只识别 `（　）`。

> 结论与处置方案见 `docs/layout-contract.md` §0.5（标「待批，未实施」）。
